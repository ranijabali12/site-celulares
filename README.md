# Rota Reparo

Tudo fica em `index.html` (HTML, CSS e JS sem dependências). Para publicar, basta subir o arquivo em qualquer hospedagem estática (GitHub Pages, Netlify, Vercel).

Para trocar o número, edite a constante `WA` no script e os links `wa.me/5511951399929`.
